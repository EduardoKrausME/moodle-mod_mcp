Cada botão representa uma passagem da sua casa atual. A descrição avisa quando houver parede, corredor, portão ou saída.

Portões de aprendizagem

  1. Avance um passo por vez, sem atravessar paredes.
  2. Ao encontrar um portão ?, leia a pergunta.
  3. Respostas incorretas recebem explicação, mas não abrem o portão.
  4. Responda corretamente para liberar a passagem.
  5. Encontre a saída E após superar os três portões.

O tabuleiro é construído com HTML e CSS, sem imagens, Canvas, bibliotecas ou arquivos externos. A lista de passagens oferece alternativa textual equivalente.
