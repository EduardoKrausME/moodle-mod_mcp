    Como revisar

    Atenção a fechamento de tags HTML, vínculo entre rótulos e campos de formulário, atributos válidos e segurança no uso de dados digitados.

    1. Leia o objetivo do trecho antes de procurar problemas.
    2. Escolha as linhas que não atendem ao objetivo.
    3. Leia a explicação e veja o antes e o depois.
    4. Encontre os dois erros ou revele as soluções restantes.
    5. Avance para o próximo trecho.

    Marcar uma linha correta não elimina os acertos anteriores. Se você revelar a solução, as linhas restantes aparecem como não identificadas, sem contar como acertos.

    Não são utilizadas imagens nem scripts externos. A correção é formativa e não modifica notas ou conclusão acadêmica do Moodle. Na ausência do SDK, toda a atividade continua funcional.
