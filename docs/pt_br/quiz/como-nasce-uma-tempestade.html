    As cenas SVG e os pictogramas das opções são desenhos originais e conceituais, sem dados de radar, imagens de satélite, fotografias, medições ou previsões reais. Os três estágios apresentam um modelo didático de célula convectiva simples; tempestades multicelulares podem ter fases simultâneas.
